# 妈妈的爱 UI 静态视觉原型

这是一组温柔亲子风的 Windows 桌面应用静态原型，面向 6-10 岁儿童。

## 文件

- `index.html`：可在浏览器中打开的完整原型画板。
- `01-child-main.png`：儿童主界面，包含今日剩余次数、倒计时和开始按钮。
- `02-time-up-dialog.png`：时间到提醒弹窗。
- `03-cooldown-rest.png`：冷却休息界面。
- `04-locked-today.png`：今日用完界面。
- `05-parent-settings.png`：家长设置界面。
- `06-play-session.png`：点击开始玩后的游戏选择/进行中页面，包含醒目的本轮倒计时和游戏列表。

## 设计方向

- 气质：温柔、安心、卡通、规则清楚、不惩罚感。
- 色彩：浅天空蓝、草地绿、暖黄、珊瑚橙，避免单一紫蓝或奶油色。
- 组件：主按钮清晰，圆角约 8px，状态同时用文字、颜色和图形表达。
- 文案：短句中文，优先让儿童快速理解当前状态。

## 原型边界

- 当前阶段只做静态视觉稿，不包含可运行应用逻辑。
- 图片中的界面文案用于视觉确认，最终实现时应在 XAML 中维护真实文本。
- 这些画板可以作为后续 WPF 页面和样式资源的视觉基准。
